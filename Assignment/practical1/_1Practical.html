Practical 1

Display Entered Name Using
ASP.NET Web Controls

ASP.NET Web Forms · C# Code-Behind · No Database Required

1 Aim

To design an ASP.NET webpage that contains:

  • Label
  • TextBox
  • Button

And displays the name entered by the user when the Button is clicked.

2 Introduction

ASP.NET Web Forms provides server-side controls that interact with C# code through events. When a user clicks a Button, an event fires on the server which can read input from a TextBox and update a Label to show a result.

User types name in TextBox
          ↓
     Button Click
          ↓
  HTTP POST to Server
          ↓
  C# Code-Behind fires
          ↓
   Label.Text is updated
          ↓
  Name displayed on webpage

This practical demonstrates basic event-driven programming and server-side control interaction in ASP.NET Web Forms.

10 Complete Default.aspx.cs

Replace the contents of Default.aspx.cs with:

c#
using System;

namespace NameDisplayApp
{
    public partial class Default : System.Web.UI.Page
    {
        protected void Page_Load(
            object sender,
            EventArgs e)
        {
        }

        protected void btnSubmit_Click(
            object sender,
            EventArgs e)
        {
            string name = txtName.Text.Trim();

            if (name != "")
            {
                lblResult.Text = "Hello, " + name + "!";
            }
            else
            {
                lblResult.Text = "Please enter a name.";
            }
        }
    }
}

15 Troubleshooting

Error: "btnSubmit_Click does not exist in the current context"

Make sure the method name in Default.aspx exactly matches the method in Default.aspx.cs.

aspx
OnClick="btnSubmit_Click"
c#
protected void btnSubmit_Click(object sender, EventArgs e)

Error: Label shows nothing after clicking Submit

Check the following:

  • runat="server" is present on the asp:Label control.
  • The ID in Default.aspx (lblResult) matches exactly in Default.aspx.cs.
  • lblResult.Text is being assigned inside btnSubmit_Click.

Error: TextBox value is always empty

Make sure you are reading txtName.Text inside the button click event handler, not inside Page_Load.

Error: Page reloads but no output appears

Verify that the Button's OnClick attribute is correctly set. If OnClick is missing, the event will not fire.

aspx
<asp:Button
    ID="btnSubmit"
    runat="server"
    Text="Submit"
    OnClick="btnSubmit_Click" />
