Practical 2

Registration Form with
ASP.NET Validation Controls

ASP.NET Web Forms · RequiredFieldValidator · RangeValidator · CompareValidator

1 Aim

To create a Registration Form in ASP.NET using:

  • RequiredFieldValidator
  • RangeValidator
  • CompareValidator

2 Introduction

Validation Controls in ASP.NET automatically validate form input before data is processed on the server. They display error messages directly on the webpage without writing manual C# validation code.

User fills Registration Form
          ↓
    Clicks Register Button
          ↓
  Validation Controls check input
          ↓
      ┌─────────────┐
      │  All Valid? │
      └─────────────┘
        ↓         ↓
       Yes        No
        ↓         ↓
   Success     Error messages
   Message     shown on page

Three validators are used in this practical:

RequiredFieldValidator  →  Ensures a field is not left empty
RangeValidator          →  Ensures a value falls within a range
CompareValidator        →  Ensures two field values match

9 Understanding the Validators

RequiredFieldValidator

Ensures a field is not submitted empty.

TextBox is empty
     ↓
RequiredFieldValidator fires
     ↓
Error message shown
     ↓
Form is NOT submitted
PropertyPurpose
ControlToValidateID of the TextBox to validate
ErrorMessageMessage shown in ValidationSummary
TextMessage shown inline next to the field

RangeValidator

Ensures a numeric or date value falls within a defined minimum and maximum.

Age TextBox value = 200
     ↓
RangeValidator checks: 18 ≤ value ≤ 100?
     ↓
No → Error message shown
     ↓
Form is NOT submitted
PropertyPurpose
ControlToValidateID of the TextBox to validate
MinimumValueLower bound of the allowed range
MaximumValueUpper bound of the allowed range
TypeData type: Integer, String, Date, etc.
ErrorMessageMessage shown in ValidationSummary

CompareValidator

Compares the value of one field with another to ensure they match.

Password        →  "abc123"
Confirm Password→  "xyz999"
     ↓
CompareValidator checks: do they match?
     ↓
No → Error message shown
     ↓
Form is NOT submitted
PropertyPurpose
ControlToValidateThe field being validated (Confirm Password)
ControlToCompareThe field to compare against (Password)
OperatorComparison type: Equal, NotEqual, etc.
ErrorMessageMessage shown in ValidationSummary

11 Complete Default.aspx.cs

Replace the contents of Default.aspx.cs with:

c#
using System;

namespace RegistrationFormApp
{
    public partial class Default : System.Web.UI.Page
    {
        protected void Page_Load(
            object sender,
            EventArgs e)
        {
        }

        protected void btnRegister_Click(
            object sender,
            EventArgs e)
        {
            if (Page.IsValid)
            {
                lblSuccess.Text =
                    "Registration successful! Welcome, "
                    + txtName.Text.Trim()
                    + ".";
            }
        }
    }
}

12 Understanding Page.IsValid

c#
if (Page.IsValid)
All validation controls pass?
          ↓
     Page.IsValid = true
          ↓
   Execute success logic

Any validation fails?
          ↓
     Page.IsValid = false
          ↓
   Success logic is skipped
          ↓
   Error messages remain on page

Page.IsValid is automatically set by ASP.NET based on all validator results on the page.

   │  CompareValidator check        │
   └────────────────────────────────┘
              ↓            ↓
          All pass       Any fail
              ↓            ↓
         Page.IsValid  Error messages
          = true        shown on page
              ↓

              ↓
   Success message displayed

16 Troubleshooting

Form submits even with empty fields

Check the following:

  • ControlToValidate is set to the correct TextBox ID.
  • runat="server" is present on both the TextBox and Validator.
  • The TextBox ID matches exactly with ControlToValidate.

RangeValidator always shows an error

Check the following:

  • Type="Integer" is set (not Type="String").
  • MinimumValue and MaximumValue are correct numbers.
  • The user is entering a numeric value, not text.

CompareValidator not detecting mismatch

Check the following:

  • ControlToValidate is set to the Confirm Password TextBox.
  • ControlToCompare is set to the original Password TextBox.
  • Operator="Equal" is set on the CompareValidator.
  • Both TextBoxes have TextMode="Password".

Success message shows even when form is invalid

Make sure Page.IsValid is checked inside the button click event:

c#
if (Page.IsValid)
{
    lblSuccess.Text = "Registration successful! ...";
}
