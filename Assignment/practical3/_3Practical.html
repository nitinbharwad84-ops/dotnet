Student CRUD Operations
Using ADO.NET

ASP.NET Web Forms · ADO.NET · SQL Server
✔ Create (Insert) ✔ Read (Display) Update Delete

1 Aim

To develop an ASP.NET Web Forms application that performs:

  • Insert — Add a new student record to the database
  • Display — Show all student records in a GridView

using ADO.NET with a SQL Server Student table.

2 Introduction

ADO.NET (ActiveX Data Objects .NET) is a data access technology used to connect ASP.NET applications with databases such as SQL Server. It provides classes to open connections, execute queries, and read results.

CRUD stands for:

C  →  Create  (INSERT)
R  →  Read    (SELECT / Display)
U  →  Update
D  →  Delete

In this practical, only Insert and Display are implemented. The flow is:

User fills Student Form
          ↓
Clicks Insert Button
          ↓
ADO.NET sends INSERT query to SQL Server
          ↓
Record saved in Student table
          ↓
LoadStudents() called
          ↓
GridView refreshed with updated data

9 Configure Database Connection

Open Web.config and add the <connectionStrings> section inside <configuration>:

xml
<configuration>

    <connectionStrings>

        <add name="CollegeDBConnection"
             connectionString="Server=.\SQLEXPRESS;Database=CollegeDB;Trusted_Connection=True;TrustServerCertificate=True;"
             providerName="System.Data.SqlClient" />

    </connectionStrings>

</configuration>
Note: If your SQL Server instance name is different, change .\SQLEXPRESS to localhost or (local) as required.

Why store the connection string in Web.config?

Web.config
     ↓
Connection String stored once
     ↓
C# reads it using ConfigurationManager
     ↓
No hardcoded strings in code
     ↓
Easy to change without modifying C# files

11 Complete Default.aspx.cs

Replace the contents of Default.aspx.cs with:

c#
using System;
using System.Configuration;
using System.Data;
using System.Data.SqlClient;

namespace StudentCRUD
{
    public partial class Default : System.Web.UI.Page
    {
        protected void Page_Load(
            object sender,
            EventArgs e)
        {
            if (!IsPostBack)
            {
                LoadStudents();
            }
        }

        private void LoadStudents()
        {
            string conStr =
                ConfigurationManager
                .ConnectionStrings["CollegeDBConnection"]
                .ConnectionString;

            using (SqlConnection con =
                new SqlConnection(conStr))
            {
                string query = "SELECT * FROM Student";

                using (SqlCommand cmd =
                    new SqlCommand(query, con))
                {
                    con.Open();

                    using (SqlDataReader reader =
                        cmd.ExecuteReader())
                    {
                        DataTable dt = new DataTable();

                        dt.Load(reader);

                        gvStudents.DataSource = dt;

                        gvStudents.DataBind();
                    }
                }
            }
        }

        protected void btnInsert_Click(
            object sender,
            EventArgs e)
        {
            string conStr =
                ConfigurationManager
                .ConnectionStrings["CollegeDBConnection"]
                .ConnectionString;

            using (SqlConnection con =
                new SqlConnection(conStr))
            {
                string query =
                    "INSERT INTO Student " +
                    "(StudentName, Age, City) " +
                    "VALUES (@Name, @Age, @City)";

                using (SqlCommand cmd =
                    new SqlCommand(query, con))
                {
                    cmd.Parameters.AddWithValue(
                        "@Name", txtName.Text.Trim());

                    cmd.Parameters.AddWithValue(
                        "@Age", int.Parse(txtAge.Text.Trim()));

                    cmd.Parameters.AddWithValue(
                        "@City", txtCity.Text.Trim());

                    con.Open();

                    cmd.ExecuteNonQuery();
                }
            }

            lblMessage.Text =
                "Student inserted successfully!";

            txtName.Text = "";
            txtAge.Text  = "";
            txtCity.Text = "";

            LoadStudents();
        }
    }
}

12 Understanding the Key Methods

LoadStudents()

Retrieves all student records from SQL Server and displays them in the GridView.

LoadStudents()
     ↓
Open SqlConnection
     ↓
Execute: SELECT * FROM Student
     ↓
SqlDataReader reads all rows
     ↓
DataTable stores the rows
     ↓
gvStudents.DataSource = dt
     ↓
gvStudents.DataBind()
     ↓
GridView displays all records

btnInsert_Click()

Inserts a new student record when the Insert button is clicked.

btnInsert_Click()
     ↓
Read txtName, txtAge, txtCity values
     ↓
Build parameterized INSERT query
     ↓
cmd.Parameters.AddWithValue(...)
     ↓
con.Open()
     ↓
cmd.ExecuteNonQuery()
     ↓
Record saved in SQL Server
     ↓
TextBoxes cleared
     ↓
Call LoadStudents()
     ↓
GridView refreshed with new record

Why Use Parameterized Queries?

c# — unsafe (do not use)
"INSERT INTO Student VALUES('" + txtName.Text + "')"
Risk: Direct string concatenation allows SQL Injection attacks.
c# — safe (use this)
cmd.Parameters.AddWithValue("@Name", txtName.Text.Trim());
Safe: Parameterized queries prevent SQL Injection and handle special characters automatically.

16 Troubleshooting

Error: "Cannot open database CollegeDB"

Check the following:

  • SQL Server service is running.
  • CollegeDB database exists in SSMS.
  • The server name in Web.config is correct (.\SQLEXPRESS or localhost).

Error: "Invalid object name 'Student'"

The table does not exist. Run this in SSMS:

sql
USE CollegeDB;

CREATE TABLE Student
(
    StudentID   INT PRIMARY KEY IDENTITY(1,1),
    StudentName VARCHAR(100) NOT NULL,
    Age         INT,
    City        VARCHAR(100)
);

Error: "The name 'ConfigurationManager' does not exist"

Add the missing namespace at the top of Default.aspx.cs:

c#
using System.Configuration;

Error: "Input string was not in a correct format"

This happens when the Age TextBox contains non-numeric text. The code uses int.Parse() which throws an error if the value is not a valid integer. Make sure the user enters a number in the Age field.

GridView shows empty after Insert

Check the following:

  • LoadStudents() is called at the end of btnInsert_Click.
  • The INSERT query executed without errors.
  • gvStudents.DataBind() is called inside LoadStudents().
